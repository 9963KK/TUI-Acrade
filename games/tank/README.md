# 坦克大战 · TANK BATTLE

守住基地，等待援军。6 个可选关卡，每关最多 3 分钟的单人终端坦克战。

## 关卡

| 关卡 | 地形与目标 | 难度变化 |
| --- | --- | --- |
| 1 · 前线阵地 | 原有砖墙阵地，12 辆敌军 | 原有节奏，最多 4 辆敌军同时在场 |
| 2 · 渡口防线 | 水道分割战场，16 辆敌军 | 增援和行动加快，需要兼顾两翼 |
| 3 · 钢铁要塞 | 钢墙形成狭道，20 辆敌军 | 增援更快，最多 5 辆敌军同时在场 |
| 4 · 交叉火线 | 错位砖墙与交叉射线，24 辆敌军 | 增援间隔 2.75 秒，需要留意侧翼 |
| 5 · 河谷围城 | 双河道与三处渡口，24 辆敌军 | 增援间隔 2.5 秒，敌军行动与开火更快 |
| 6 · 最后防线 | 交错钢墙与迂回通路，24 辆敌军 | 增援间隔 2.25 秒，最多 6 辆敌军同时在场 |

默认从第 1 关开始。按 `L` 打开选关列表，用方向键或 `W` / `S` 选择，Enter 开始；Esc 返回原战斗。选关期间倒计时与战场冻结，确认选关会开始新局。

胜利后 Enter 进入下一关；最终关完成后 Enter 回到选关列表。`R` 始终重试当前关，失败后 Enter 也重试当前关。每关重新获得 3 条命、独立计分，最高分仍保存为所有关卡中的最高单关成绩。

## 玩法

- 消灭当前关卡的全部敌军可提前获胜；倒计时结束且基地仍在也算获胜。
- 3 条命，出生和复活后有 3 秒护盾；基地被击中或生命耗尽立即结束。
- 砖墙可破坏，钢墙不可破坏，水域挡车不挡炮；双方炮弹可以互相抵消；玩家炮弹不会破坏基地。
- 每击毁一辆得 100 分；获胜另得剩余生命 × 200 + 剩余秒数 × 5。

| 按键 | 功能 |
| --- | --- |
| WASD / 方向键 | 移动、转向 |
| 空格 / J | 射击 |
| F | 开关自动连射 |
| P / Esc | 暂停、继续 |
| ? / H | 说明 |
| L | 选择关卡，确认后开始新局 |
| Q | 结束本局并退出（从游戏厅启动时返回大厅） |
| Enter | 胜利后下一关；失败后重试；最终关胜利后选关 |
| R | 结算后重试当前关 |

## 运行

- 从游戏厅：在仓库根目录运行 `./play.sh --game tank`
- 单独运行：`cd games/tank && python3 -m tank_battle`

需要 80 × 24 以上的 UTF-8 终端。使用 Python 标准库 `curses`，因此当前只支持 macOS 与 Linux；Windows 需要改用其它终端后端后才能声明支持。

## 存档

只保存最高分（`save_mode: records`），文件为数据目录下的 `scores.json`：

- 由游戏厅启动时写入平台分配的 `TUI_ARCADE_DATA_DIR`；
- 单独运行时使用同一位置：Linux `~/.local/share/tui-arcade/games/tank/`，macOS `~/Library/Application Support/TUI Arcade/games/tank/`（设置了 `XDG_DATA_HOME` 或 `TUI_ARCADE_HOME` 时以其为准）。

首次运行会从旧位置 `~/.local/share/tui-arcade/scores.json` 导入最高分，旧文件保留不删。记录文件无法读取时不会被覆盖，而是另存为 `scores.json.corrupt` 并在结算时提示。

## 开发

- `tank_battle/rules.py`：不依赖终端的规则，可直接单元测试。
- `tank_battle/levels.py`：关卡地图与敌军节奏配置，和战斗规则分离。
- `tank_battle/app.py`、`glyphs.py`：终端界面与字形，使用可选工具包 `arcade_kit`（仓库 `kit/`）；打包安装包时须把 `arcade_kit` 一并打入。
- `tank_battle/storage.py`：最高分读写与迁移。

### 添加关卡

在 `levels.py` 的 `LEVELS` 中追加一个 `Level`，提供名称、简介和 19 行 × 29 列的地图；`.` 为空地、`#` 为砖墙、`S` 为钢墙、`~` 为水域。基地、玩家出生点和 3 个敌军出生点必须留空，并保留可打通或绕行的进攻路径。每局独立生成地形，破坏砖墙不会影响重试或其他关卡。

`target` 设置敌军总数，`spawn_interval` 设置增援间隔，`max_enemies` 设置同时在场上限，`move_delay` / `fire_delay` 设置行动与开火间隔范围（秒）。选关列表自动滚动，胜利条件、帮助和 HUD 自动读取配置；敌军图标最多显示 24 个，剩余数量以数字为准。

验证关卡、规则、界面和真实终端操作：

```sh
python3 -m unittest discover -s tests -p 'test_tank*.py'
```

这组测试可在仓库根目录单独运行，无需构建 Go 平台。
